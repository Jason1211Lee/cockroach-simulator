# 2026-11-25：人類外型、個性與控制權分離

## 本次小目標與依賴
將 3D 人類反應從直接讀取介面選項改為獨立角色資料，落實相同外型可配不同反應、玩家控制時不套 AI 自動移動的要求。已讀最新 GAME_PLAN.md、3d.html、頁面測試、根目錄／docs 與未合併 PR。僅 PR #1 開啟，頭為 1a015a5e3f25819aa8eb538440c016a5f74cb44e；沿用 docs/game-foundation，不另開 PR、不合併。根目錄／docs 未列出 AGENTS.md。

## 完成內容
- 新增 human-profile.mjs，建立不可變的 appearanceId、personalityId、controller 三個獨立欄位，拒絕不支援的設定。
- appearanceId 固定對應現有 procedural-human-v1 暫代模型；尚未提供其他外型或寫實模型選擇。
- personalityId 為 shy／chase／spray，controller 為 ai／player。切換角色或個性時由 reset 建立新設定並清除上一局攻擊狀態。
- 驚嚇判定、NPC 反應與追打／噴藥標記讀取角色設定，不再直接以介面值當作 AI 狀態。
- NPC 反應更新以 controller=ai 作為條件。玩家控制人類時保留自身輸入，個性不會強制啟用 AI 逃跑或攻擊。
- 三種個性不重建模型或子網格，持續使用同一人類外型。

## 驗收步驟與完成標準
1. 以靜態 HTTP 伺服器提供整個分支（包含新增 human-profile.mjs），開啟 3d.html。
2. 選蟑螂陣營，分別選膽小／追打／噴藥（每次切換會重開），靠近人類。
3. 同一人類造型應依設定逃離、產生追打預警或噴藥預警，不能因個性而更換造型。
4. 改選人類陣營，不輸入移動，即使 AI 蟑螂接近，也不應被個性強制移動或自動發動 NPC 攻擊。
5. 切回蟑螂時恢復對應個性 AI，不能殘留上一局攻擊狀態。
