# 蟑螂模擬器 · 午夜廚房

單人俯視角 2D 瀏覽器遊戲原型，電腦與手機共用 JavaScript Canvas 程式。無執行期套件、無 CDN 素材、無後端。採原生 Web 技術是為了讓第一版容易下載與測試；尚未打包原生 App。

## 試玩

第一版位於 `docs/game-foundation` 分支（PR #1），尚未自動合併或部署網站。

1. 切換到該分支，下載 ZIP 並解壓縮，電腦直接用瀏覽器開啟 `index.html`。
2. 若要讓同一 Wi-Fi 的手機測試：在解壓縮資料夾執行 `python3 -m http.server 8000 --bind 0.0.0.0`。
3. 手機瀏覽器開啟 `http://電腦的區網IP:8000`，橫放遊玩。請只在信任的區域網路使用，結束後 Ctrl+C 停止伺服器。

GitHub 原始碼頁面本身不會執行 HTML；目前沒有公開試玩網址。

## 操作與目標

- 電腦：WASD／方向鍵移動，E 互動，Q 驚嚇，Space 飛行，P 暫停。
- 手機：左側搖桿移動、右側動作按鈕；支援暫停與重開。
- 先把三份碎屑各自帶回左下角藏身處，交付共得 30 XP，升至 Lv.2 並提升力量與速度。
- 接近藍色膽小人類按驚嚇，首次獲得 20 XP；搬回右上角大型食物再得 30 XP，Lv.3 解鎖飛行。
- 飛越右下方矮櫃抵達星星，再返回藏身處獲勝。紅色人類追打，紫色人類噴毒霧；橘色範圍是攻擊預警。
- 飛行可避開拖鞋與跨越矮櫃，但不能穿牆，也不免疫毒霧。生命歸零失敗，可重開。
