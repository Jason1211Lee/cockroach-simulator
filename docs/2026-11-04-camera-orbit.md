# 2026-11-04 拖曳鏡頭

小目標：在遊戲 Canvas 上拖曳即可左右環視與上下調整鏡頭；左側搖桿仍控制角色。

實作：新增 camera-orbit.mjs。水平位移改變 yaw，垂直位移改變 pitch，pitch 限制在 0.12–1.15 弧度；使用球面偏移保持跟隨距離。角色仍沿鏡頭方向移動。Canvas 使用獨立 pointer 所有權，取消／放開釋放，失焦、背景切換、resize 與重開清除鏡頭 pointer，重開恢復預設俯角。保留原左右鏡頭按鈕。

驗收操作：拖曳空白遊戲區看向左右及上方，確認俯角不翻轉；同時推左搖桿移動；放開鏡頭手指、切到背景後回來，不應繼續旋轉。

已執行：node test-camera-orbit.mjs 通過水平轉向、俯角上下限、零位移、反向拖曳還原、固定相機距離與無效輸入檢查。test-input-reset.cjs、test-flight-controls.mjs、test-damage-cooldown.cjs、test-interaction-range.mjs 皆通過。抽取頁面 module 後 node --check 通過，另確認 pointer 所有權與重置掛接。

驗證限制：以上是數學／模擬邏輯與語法驗證，尚未進行實際瀏覽器或手機多指操作。未驗證相機遮擋；相機仍可能穿入家具。程序角色模型與寫實資產未改動。此變更提交 PR #1，未合併、未更新試玩網站。

下一步：在可操作的 WebGL 測試環境中跑完整移動、環視、飛行流程，處理鏡頭遮擋與三維碰撞，再發布經過實玩檢查的版本。
