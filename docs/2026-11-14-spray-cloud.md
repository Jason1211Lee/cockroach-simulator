# 2026-11-14：噴藥預警與有限時毒霧

## 本次小目標與前置確認
讀取最新根目錄（未見 AGENTS.md）、GAME_PLAN.md、3D 程式與整合測試、未合併 PR。PR #1 仍開啟且為唯一未合併 PR，沿用 docs/game-foundation。將噴藥型的接觸立即扣血替換為可預判、可離開且會消散的區域攻擊。

## 實作步驟
1. 新增 spray-attack.mjs：idle → windup 0.8 秒 → cloud 3 秒 → recovery 4 秒。射程為水平 2.2、高度不超過 1.5。
2. 預警開始鎖定玩家當時的地面位置，不持續追蹤。黃色圓盤表示預警，綠色半透明圓柱表示毒霧，均為程序暫代視覺。
3. 毒霧半徑 0.85、高度 0–1.5；產生時及之後每秒判定一次，每次 10 HP，仍受共用傷害冷卻限制。持續待在同一毒霧內共三次判定，毒霧到期後不再傷害。
4. 飛行旗標不免疫毒霧：低空仍在毒霧體積內會受傷；離開水平範圍或飛到體積上方可避傷。
5. 噴藥 NPC 平時靠近至適當距離或後退，預警與毒霧期間停步。暫停凍結所有倒數，切換選角或重開清除毒霧與計時器。人類玩家不套用此 AI。

## 驗收與實際結果
- node test-spray-attack.mjs：通過 0.8 秒預警、3 秒存在、三次每秒傷害事件、4 秒冷卻、固定落點及高度／半徑界限。
- node test-page-runtime.mjs：通過預警不傷害、傷害節流、毒霧消散後無傷、暫停凍結、離開區域、低空飛行受傷／飛高避傷、切換人類清除狀態、失敗與重開。既有追打、成長、搬運、選角、鏡頭與人類操作測試通過。
- node test-chase-attack.mjs、node test-progression.mjs、node test-movement-controls.mjs 與抽出 HTML module 的 node --check：通過。
- 整合測試直接設定角色位置建立情境，使用 Node VM 與 DOM／Three.js 替身；visible 和文字內容測試不是實際 WebGL 畫面驗證。本次沒有執行瀏覽器、手機真機、多指操作或效能測試。

## 手動驗收流程
選蟑螂／噴藥人類 → 接近至黃色預警出現 → 留在範圍確認綠霧產生後才扣血 → 重開並在預警時離開，應無傷 → 飛行型低空留在範圍應受傷 → 升高超過綠霧上緣應避開 → 暫停確認倒數凍結 → 重開確認毒霧消失。
