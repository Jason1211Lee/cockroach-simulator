# 2026-11-15：家具遮蔽人類視線

## 小目標與前置確認
先讀取最新根目錄（未見 AGENTS.md）、GAME_PLAN.md、3D 程式與整合測試、相機遮擋模組及未合併 PR。PR #1 是唯一未合併 PR，沿用 docs/game-foundation。這次讓家具阻擋 NPC 新偵測／攻擊與隔物互動，不重建設計概要。

## 執行步驟
1. 新增 visibility.mjs，重用既有線段與 AABB 交集計算，設定 margin=0；從人類腳部位置上方 1.6 的眼睛到蟑螂上方 0.08 的身體取樣點判斷視線。使用場景既有 cameraBoxes（牆、櫃體與桌板等包圍盒）。
2. 膽小、追打、噴藥人類在被家具擋住時不追近／逃離，idle 狀態不啟動攻擊；恢復視線後可重新反應。
3. 已開始的攻擊倒數／冷卻仍推進，避免狀態被永久凍結。拖鞋揮擊當下另驗視線，隔物不扣血。
4. 驚嚇與玩家人類的動作也驗視線，隔物不給 XP 或命中分數，畫面回報家具遮擋。
5. 已生成毒霧獨立存在並正常消散，不因施放者看不見玩家而立即消失。

## 手動驗收流程
在櫃體兩側接近人類 → 確認沒有開始新攻擊或隔物驚嚇計分 → 繞出櫃體露出視線 → 確認 NPC 恢復反應 → 預警後躲回遮蔽，確認拖鞋不穿家具命中 → 已有毒霧應仍按原計時消散。
