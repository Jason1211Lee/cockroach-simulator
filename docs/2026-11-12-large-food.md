# 2026-11-12：大型食物搬運與交付

## 小目標與前置確認
讀取根目錄（未見 AGENTS.md）、最新 GAME_PLAN.md、程式與未合併 PR，確認 PR #1 仍開啟，沿用 docs/game-foundation。今天讓力量 2 實際控制大型食物搬運，完成一條可驗收的收集／升級／交付循環。

## 執行步驟
1. 加入橘色大型食物（地面位置 x=4,z=2）及綠色交付點（x=-4,z=3）。均為程序暫代物件，沒有使用外部資產。
2. F／搬運按鈕：靠近食物且力量達 2 才可搬運，空中不能拾取；搬運時減速 20% 且不能起飛。
3. 再按搬運：在交付點三維距離 0.6 內交付，其他地方放下，可重新拾取。交付只獎勵一次 30 XP。
4. HUD 顯示待搬運／搬運中／已交付。蟑螂勝利改為三份小食物與大型食物交付均完成，人類三次處理目標不變。
5. 暫停、終局及人類角色不接受搬運；重開或切換選角清除搬運狀態。

- 測試使用 Node VM 與 DOM／Three.js 替身；本次沒有執行 WebGL 畫面、桌面瀏覽器操作、手機多指／真機或效能驗收。

## 手動驗收流程
選蟑螂 → 嘗試搬運橘色食物，應提示力量不足 → 收集三份食物（或首次驚嚇加一份食物）升級 → F／搬運 → 移動應較慢，大食物跟隨 → 在綠色區按 F 交付 → 檢查 XP、任務及勝利 → 重開清零。
