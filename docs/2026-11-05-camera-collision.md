# 2026-11-05 鏡頭遮擋處理

小目標：角色與理想鏡頭位置之間有牆、櫃體或桌板時，相機停在第一個遮擋物前，保留 0.12 場景單位距離。

實作：camera-collision.mjs 使用線段與軸對齊包圍盒交點，找最近遮擋比例。場景 box 建立時登記尺寸較大的幾何體，排除小食物。跟隨鏡頭先計算環視位置，再沿觀察錨點縮近。包含地板、牆、櫃體與桌板；目前細桌腳沒有納入。

驗收步驟：角色靠近牆或櫃體，拖曳鏡頭繞到遮擋方向，相機應縮近；離開遮擋方向恢復原跟隨距離。

已執行：test-camera-collision.mjs 共 8 項斷言通過，涵蓋無遮擋、預留距離、高於障礙、平行線未命中、零長度、起點位於盒內、最近障礙及反向線段。test-camera-orbit、test-input-reset、test-flight-controls、test-damage-cooldown、test-interaction-range 全部通過。抽取頁面 module 做 node --check 通過；確認頁面已接入計算。

限制：尚未做真實瀏覽器／手機視覺及操作驗證。此方法是相機中心線與包圍盒，尚未涵蓋近裁切面寬度，也沒有平滑恢復距離。錨點若在物體內，相機會收至錨點，需後續配合角色三維碰撞改善。未宣稱所有穿模解決。未部署試玩網站、未合併 PR #1。

下一步優先補實際 WebGL 視覺驗證與角色空中碰撞，確認移動／環視／升降完整操作後再發布。
