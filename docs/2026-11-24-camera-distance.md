# 2026-11-24：可選鏡頭距離

## 小目標與現況
讓玩家可自行拉遠第三人稱鏡頭，改善固定距離不易觀察環境的問題。已讀取最新 GAME_PLAN.md、3d.html、camera-orbit.mjs、頁面測試、根目錄／docs 目錄與未合併 PR。僅 PR #1 開啟，頭為 b98781af1a742fb1164542aa00ef8d3ffae5bd3b；沿用 docs/game-foundation，不另開 PR、不合併。兩目錄未列出 AGENTS.md。

## 實作
- 上方新增有「鏡頭距離」無障礙名稱的選單：標準／寬廣，預設標準。
- 標準沿用蟑螂 2.4、人類 3 個場景單位；寬廣為各自標準的 1.5 倍（3.6／4.5）。這些為遊戲鏡頭參數。
- 保留原有角色高度的注視錨點及 yaw／pitch，拉遠時同一俯仰角也會提高鏡頭位置。
- 同一家具遮擋函式處理兩種模式，空間狹窄時實際距離可能低於選擇值。
- 選單不觸發 reset，暫停中也可調整；重開或切換角色保留該頁面的選擇，重新載入回預設標準。
- 操作說明補充切換方式。不是第一人稱、俯視角切換，也沒有改變模型或飛行能力。

## 執行／驗收步驟與完成標準
1. 靜態 HTTP 伺服器開啟分支 3d.html，在空曠處切換上方「鏡頭：標準／寬廣」。
2. 寬廣應拉遠鏡頭，同一 pitch 下位置較高；拖曳環視／俯仰仍能使用。
3. 家具或牆壁在鏡頭路徑上時仍應縮近，不能因選寬廣就穿過遮擋物。
4. 切換前後 HP、經驗與食物進度不重置；暫停時切換不推進遊戲。
5. 重開保留距離選擇；人類模式使用自身高度與距離。
