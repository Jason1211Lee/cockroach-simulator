# 蟑螂模擬器：設計概要與開發路線

## 一頁式遊戲設計概要

**體驗目標**：玩家扮演弱小卻靈活的蟑螂，在人類房間裡偷吃、製造驚嚇，透過成長開啟新的逃生與探索方式。風格以幽默、生存與風險選擇為主。

**最小範圍**：單人、單一廚房、俯視角 2D 原型；以簡單形狀代替美術。開發技術尚待確認，先保持設計不依賴引擎。

**核心循環**：離開藏身處 → 觀察人類 → 選擇食物或驚嚇任務 → 承擔暴露風險 → 返回安全區 → 取得經驗與升級 → 挑戰新路線。

**玩家操作**：移動、互動／搬運、驚嚇、飛行（解鎖後）、暫停與重開。移動使用 WASD／方向鍵；其他按鍵在原型階段配置並顯示於畫面。

**任務**：拾取並帶回 3 份食物；成功嚇到膽小 NPC 1 次；帶回需力量 2 的大型食物；解鎖飛行後跨越地面障礙。每項任務只能領取一次完成獎勵。

**成長**：初始等級 1、經驗 0、力量 1。累計經驗達 30 升至等級 2，移速增加 10%、力量升至 2；達 80 升至等級 3，解鎖短暫飛行。單份食物 10 經驗，首次驚嚇任務 20 經驗，大型食物任務 30 經驗。以上為待測試的初始數值。

**NPC 差異**：膽小型發現玩家後逃跑；追打型追逐並在預警後揮拖鞋；噴藥型接近射程後產生有預警與持續時間的毒霧。飛行可避開地面揮擊，仍會受到毒霧影響。

**勝敗與回饋**：生命值 100；受擊短暫無敵，避免同一攻擊重複扣血。生命歸零顯示失敗並可重開；完成食物、驚嚇、大型食物與飛行任務後返回安全區獲勝。任務、經驗、等級、生命、飛行冷卻均可見。

**暫不擴充**：多人、開放世界、寫實攀牆、繁複裝備與正式美術；先完成一局約 5–10 分鐘的核心體驗。

## 可實作規格

- 任務狀態：未啟用 → 進行中 → 完成；獎勵獨立記錄 claimed，避免重複領取。食物以唯一 ID 記錄，交付後移除。
- NPC 共用狀態：巡邏 → 發現 → 個性反應 → 搜索 → 返回巡邏。偵測需距離與視線均成立；遮蔽物阻擋視線，離開視線 2 秒進入搜索，搜索 3 秒後返回。安全區不受攻擊。
- 膽小型：逃離玩家，接觸牆面改走可通行方向；首次有效驚嚇只計一次任務進度。
- 追打型：追逐至攻擊距離；先顯示 0.6 秒預警，再於固定落點判定一次傷害；冷卻 1.5 秒。
- 噴藥型：射程內先預警 0.8 秒，再建立持續 3 秒毒霧；每秒扣血最多一次；冷卻 4 秒。
- 飛行：持續 2 秒、冷卻 5 秒；可跨低矮障礙與避開地面攻擊，不可穿牆。結束前尋找合法地面落點，找不到則返回起飛點。
- 搬運：力量不足時提示需求；搬運大型食物時移速降低 20%。交付後恢復。
- 重開：重置玩家、食物、NPC、任務、獎勵旗標、飛行與傷害計時器。原型先不做跨局存檔。

## 每日小目標與驗收

每次工作完成一個最小變更，記錄實際驗證結果；遇到依賴或錯誤先修復，不按日期假裝完成。

| 順序 | 小目標 | 執行步驟 | 完成標準 |
|---|---|---|---|
| 1 | 確立設計 | 閱讀概要、確認 2D 與開發技術、凍結最小範圍 | 技術決策與操作方式寫入 README |
| 2 | 可移動房間 | 建立場景、玩家、牆與碰撞 | 方向移動穩定，斜向不加速，不穿牆 |
| 3 | 食物循環 | 放 3 份食物，實作拾取、搬運與交付 | 同一食物只交付一次，安全區顯示數量 |
| 4 | 任務系統 | 建立任務狀態、事件與獎勵旗標 | 進度可見，完成獎勵不重複 |
| 5 | 經驗與升級 | 實作門檻、移速與力量；放大型食物 | 30／80 經驗正確升級，力量限制有效 |
| 6 | NPC 偵測 | 巡邏、視線、搜索與重置 | 躲到遮蔽物後能脫離偵測 |
| 7 | 膽小型 NPC | 驚嚇輸入、條件判定、逃跑 | 有效驚嚇計分，距離外不計分 |
| 8 | 追打型 NPC | 追逐、預警、落點、傷害冷卻 | 可躲避預警，一次揮擊只扣一次血 |
| 9 | 噴藥型 NPC | 預警、毒霧範圍、持續傷害 | 毒霧會消失，飛行仍會受傷 |
| 10 | 飛行能力 | 等級鎖定、持續時間、冷卻與安全降落 | 未解鎖不能飛，可越低障礙且不穿牆 |
| 11 | 完整一局 | 整合勝敗、提示與重開 | 可從新局玩到勝利或失敗再重開 |
| 12 | 驗收與調整 | 跑驗收表、修阻塞問題、補啟動說明 | 必要案例通過，提供可重現的啟動方式 |
