# 2026-11-02 飛行與傷害冷卻分離

目標：起飛不得產生額外無敵效果，受傷也不得重寫飛行冷卻。

問題：原本 cool 同時用於起飛、玩家人類處理動作，以及 NPC 對蟑螂傷害。起飛設 cool=8，導致附近噴藥型的接觸傷害被擋住 8 秒。傷害又會把 cool 改為 1，混淆技能恢復時間。

修正：新增 damageCooldown，獨立遞減與重置；NPC 命中只更新 damageCooldown，不修改 cool。生命限制最小為 0。地面拖鞋依既有規則在飛行期間無效；噴藥型接觸傷害不受起飛冷卻保護。

驗證：node test-damage-cooldown.cjs 通過，直接從 3d.html 擷取實際命中條件與處理區塊，於 VM 驗證噴藥命中、冷卻互不覆蓋、重複傷害限制、飛行／地面追打、膽小與距離限制、死亡生命值、計時與重置掛接。另 test-input-reset.cjs、test-flight-controls.mjs 均回歸通過。

驗收步驟：飛行型起飛並接近噴藥 NPC，受傷後飛行冷卻仍依原進度走；1 秒內重複接觸不應再扣血；地面接近追打型可受傷，飛行中則避開地面攻擊。

驗證限制：這次是 Node VM 與函式測試，沒有實際瀏覽器畫面或手機觸控驗證。噴藥仍是暫代接觸傷害，不代表獨立毒霧機制完成。未部署到線上試玩網址，未合併 PR。

下一步：補三維碰撞與實際瀏覽器操作，確認自由升降和鏡頭體驗，再部署可驗收版本。
