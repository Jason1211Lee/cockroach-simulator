# 2026-11-01 飛行高度控制

小目標：飛行型能主動升高、降低、提早降落；不再只升到固定高度。

實作：新增 flight-controls.mjs，升降每次調整 0.25，目標高度限制 0.25–2.2；起飛目標為 0.8。高度使用原有平滑插值。再次按動作會結束飛行；持續時間與冷卻沿用 5 秒及起飛起算 8 秒。重開／換角重設高度。狀態列顯示即時高度。此處單位是場景座標，不是生物數據。

步驟：選飛行型 → 起飛 → 按升高／降低 → 再按動作降落；冷卻結束後才能再起飛。

完成標準與已執行驗證：node test-flight-controls.mjs 通過升高、降低、上下限、飛行到期地面目標及有效飛行目標共 7 項斷言；node --check 對抽取的頁面模組通過；node test-input-reset.cjs 回歸通過。另確認升降模組、降落與重置掛接存在。

限制：尚未執行瀏覽器或手機真機操作；沒有宣稱手感驗收。場景碰撞仍採原有平面判定，尚不能飛越櫃體或停在桌面；沒有完整三維升降碰撞與安全落點。動作鍵仍與人類近距離處理共用，人物攻擊／噴藥動畫未補完。
