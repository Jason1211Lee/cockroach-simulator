# 2026-11-28：追打 NPC 拖鞋手勢

## 小目標與前置工作
接續基本人類行走群組，補上追打型 NPC 的抬手、前揮與收手，讓攻擊預警更容易辨識。已讀最新 GAME_PLAN.md、3d.html、chase-attack.mjs、頁面測試、根目錄／docs 與未合併 PR。僅 PR #1 開啟，頭為 2f3e0682de0dc9873a051e33147e4f55e5018c68，沿用 docs/game-foundation，不新增 PR、不合併。根目錄／docs 未列出 AGENTS.md。

## 實作
- 用程序橢球建立拖鞋底與鞋帶，附於既有右臂群組，只有 AI 追打型顯示；其他個性與玩家人類不顯示此 NPC 道具。
- 共用既有 chaseAttack.remaining：0.6 秒預警的前 0.45 秒抬手，最後 0.15 秒向前揮；進入 recovery 時到達出手手勢，再用前 0.3 秒回到原有行走動作。
- 暫停時計時不變，因此手勢凍結；重開清除姿態，切換個性或陣營隱藏道具。
- 不改命中範圍、傷害、預警或冷卻；揮空也會播放手勢，一次攻擊仍只判定一次傷害。

## 明確限制
這是暫代模型的程序手勢，不是完成的拍地動作。拖鞋由單段手臂帶動，尚無彎腰／屈膝／手臂 IK、手掌握持或鞋底落地接觸；命中仍依橘色固定地面落點判定，不由拖鞋模型碰撞決定。動畫與判定共用時間邊界，不代表模型已實際接觸蟑螂。人物與道具皆為原型程序造型，沒有新增外部美術資產。

## 驗收步驟與標準
1. 以靜態 HTTP 伺服器開啟分支 3d.html，選蟑螂／追打人類並接近。
2. 橘色預警時人類應抬手，預警結束前向前揮，之後收手；離開固定落點應可閃避。
3. 動作中暫停應凍結，重開應回中立姿態。
4. 改選膽小／噴藥或玩家人類，不應顯示追打 NPC 的拖鞋。
