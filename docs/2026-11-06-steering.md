# 2026-11-06 轉向與型態機動差異

小目標：蟑螂的頭朝向與行進方向一致，型態的轉向速度實際影響移動路徑，方向鍵與 WASD 行為一致。

原模型頭部位於局部 -Z，原本 atan2(x,z) 朝向相反。新增 movement-controls.mjs，使用 atan2(-x,-z) 並依鏡頭 yaw 轉換。每幀沿最短角度轉向，限制角速度，移動沿當前頭朝向前進，因此轉彎會形成短弧而非模型倒退滑行。類比輸入保留推動幅度，合併鍵盤輸入後限制最大幅度 1。

依設計初值設定疾走／靈巧／飛行地面速度為 1.38／1.2／1.02，轉向角速度 10／12／8.5 rad/s；這些是遊戲平衡假設，不是生物數據。三者均不變更飛行資格。方向鍵新增支援並防止頁面捲動。

驗收操作：分別選三種型態，在空曠地連續做 90 度與 180 度轉向，模型頭應朝行進方向；靈巧型轉彎較緊，飛行型較寬。使用方向鍵和 WASD 應得到相同方向。小幅推搖桿應較慢。

已執行：test-movement-controls.mjs 通過四方朝向、方向鍵一致、斜向幅度限制、類比幅度、轉向速率上限、不超轉、跨 ±π 最短轉向、型態取捨與 30/60 FPS 轉角一致檢查。頁面模組 node --check 通過；既有輸入重置、飛行、傷害、互動距離、鏡頭環視與遮擋測試均通過。

限制：尚未做真實瀏覽器或手機操作，不能宣稱手感已驗收。尚無爬行骨架動畫與寫實品種模型；不是完整三維碰撞。未更新線上網站，也未合併 PR #1。下一步應優先補實際 WebGL 試玩與操作錄影，再依測試結果調整角速度，避免只憑計算判斷體驗。
