# 2026-11-13：追打型 NPC 預警與固定落點

## 本次小目標
將 3D 追打型 NPC 的接觸立即扣血改為可閃避的預警揮擊。先讀取最新根目錄（未見 AGENTS.md）、GAME_PLAN.md、程式、整合測試與未合併 PR；只有 PR #1，沿用 docs/game-foundation，不建立重複 PR。

## 執行步驟與行為
1. 新增 chase-attack.mjs，明確區分 idle、windup、recovery。
2. 人類距蟑螂水平距離 0.9 內且蟑螂高度不超過 0.3 時開始蓄力，記住蟑螂當下地面位置。
3. 0.6 秒蓄力期間停止 NPC 移動，顯示橘色半徑 0.45 的落點與文字倒數。落點不追蹤玩家；揮擊後落點短暫保留。
4. 倒數結束只產生一次揮擊事件；以落點為中心的三維距離 0.45 內才扣 20 HP，保留獨立傷害冷卻。飛離地面足夠高度可避開，不靠 flight 旗標直接給予無敵。
5. 揮擊後冷卻 1.5 秒；倒數在離開追蹤範圍後仍會完成，但不會改變落點。暫停凍結狀態，重開／選角清除預警與計時器。

## 手動驗收步驟
選蟑螂與追打人類 → 接近直到出現橘色圈與倒數 → 留在原地應在預警後扣一次血 → 重開並在預警時移開，應閃過 → 選飛行型在揮擊前飛高，應避開 → 預警時暫停，再繼續，倒數應保留 → 失敗後重開恢復 HP 並清除預警。
