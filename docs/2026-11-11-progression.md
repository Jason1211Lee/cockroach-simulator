# 2026-11-11：3D 食物與驚嚇經驗循環

## 本次小目標
讓既有 3D 場景中的食物與首次驚嚇產生一次性經驗，玩家可在通關前升級，且三種型態速度差異不被抹平。

## 執行步驟與實作
1. 先讀分支根目錄（未見 AGENTS.md）、最新 docs/GAME_PLAN.md、未合併 PR 集合與現有 3D／整合測試。唯一未合併 PR 為 #1，沿用 docs/game-foundation，不新增重複 PR。
2. 新增 progression.mjs：每局獨立 XP 與 claimed Set，獎勵來源 ID 去重；30 XP 等級 2、80 XP 等級 3，等級 2 起速度倍率 1.1、力量 2，數值封頂。數值為遊戲平衡，不是生物測量。
3. 食物每份 +10 XP；新增 E／手機「驚嚇」按鈕，只對 1.3 單位三維距離內的膽小人類發放首次 +20 XP。其他個性、距離外、暫停、結束與人類玩家不發放。
4. HUD 顯示等級、XP 與力量；移動計算套用同一有上限倍率；重開與選角重置進度。膽小人類沿用原本近距離逃跑 AI，沒有新增人物動畫。

## 完成標準與測試
- node test-progression.mjs：通過 29／30／79／80 XP 邊界、獎勵去重、非法獎勵、成長上限及各型態速度排序。
- node test-page-runtime.mjs：通過近／遠距離驚嚇、首次獎勵防重複、食物 XP、防重複拾取、HUD、重開及實際迴圈中的升級移速比值 1.1；既有飛行、鏡頭、暫停與人類操作整合案例通過。測試直接設定角色位置以觸發互動，使用 DOM／Three.js 替身，不是真正 WebGL。
- node test-movement-controls.mjs：通過轉向、類比／斜向速度及型態差異回歸。
- 抽取 HTML module 後 node --check：通過。
- 手動驗收流程：選蟑螂／膽小人類 → 靠近按 E 或驚嚇 → XP 20 → 找一份食物 → XP 30、Lv 2、移速提升 → 再次驚嚇不增加 XP → 重開回到 XP 0。
