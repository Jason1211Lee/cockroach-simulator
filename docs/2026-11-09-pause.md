# 2026-11-09 暫停與背景保護

小目標：3D 模式切到背景或失焦時暫停，回來後由玩家按繼續，避免離開期間受傷或耗掉飛行時間。

新增暫停／繼續按鈕與 paused 狀態，暫停時跳過角色、NPC、傷害、食物、分數與冷卻／飛行更新，動作及升降按鈕無法改變遊戲狀態。暫停時清除鍵盤、搖桿與鏡頭 pointer；背景切換不會自動恢復。重開／換角解除暫停並重置。

驗收步驟：飛行型起飛 → 暫停 → 等待並按動作／升高 → 角色、生命與計時應保持 → 繼續後才恢復倒數；切背景再返回，必須按繼續；重開應回到可操作狀態。

已執行：node test-page-runtime.mjs 通過，新增暫停跨 40 幀角色／NPC 位置、生命、冷卻、飛行與分數完全不變，繼續後恢復倒數、隱藏事件自動暫停、可見事件不自行恢復、重開解除暫停等斷言，連同原本頁面流程通過。抽取 module 後 node --check 通過。

驗證限制：測試使用替代 DOM 與 Three.js，沒有真正 WebGL 渲染、瀏覽器生命週期或手機真機切背景驗證。鏡頭按鈕仍可調整觀察角度，不會推進遊戲。未部署網站、未合併 PR #1。本次不代表完整遊戲驗收完成。
